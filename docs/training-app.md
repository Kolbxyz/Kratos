# Training app and APK

This document describes how the training app is generated from the lessons, how it is structured, and how the Android APK is built.

## Content
- Every lesson becomes a unit and every `##` chapter a step (`src/lib/etapes.ts`): reading cards that reproduce the lesson text verbatim (notes kept as « source » links), followed by the chapter's questions.
- Questions are generated by `src/lib/exercices.ts` from the lessons' `<Chiffre>`, `<Citation>` and `<Timeline>` blocks. No question is written by hand, and every answer displays the source of its block.
- « Complétez la phrase » questions hide a bold term, a percentage or a year from a sentence of the step. They add no fact.
- A chronology becomes an exercise only when every date parses and the dates are in order.
- `src/pages/app/contenu.json.ts` publishes the content (lessons, steps, `lectures:`). Its shape is a contract with installed APKs (`AGENTS.md`, *Cross-project contracts*).

## Client (`public/app/`)
HTML, CSS and JS modules, without a build step.

| File | Role |
| --- | --- |
| `js/main.js` | Entry point: tabs and theme |
| `js/ecrans/*.js` | One file per screen |
| `js/nav.js` | Navigation stack and predictive back |
| `js/etat.js` | Local storage of progress and settings |
| `js/contenu.js` | Loads the bundled content, then the published one |
| `perso.js` | Track mascots: face, prop, motion and lines |
| `app.css` | Material 3 color roles and components |

- Material 3: color roles in `app.css`; icons from Material Symbols Rounded, subset in `polices/`. An icon name is added to the subset before it is used.
- Fonts: Newsreader for reading, Figtree for the interface, both self-hosted in `polices/` (`LICENCES.txt`).
- Every track is a separate class; the Apprendre and Bibliothèque tabs are filtered by class.
- Mascot lines encourage the learner and state no fact. Mascot bodies keep a contrast of at least 3:1 with bold white text.
- Animations use the M3 standard and emphasized easing curves, without bounce.

## APK (`mobile/`)
- Capacitor wraps `dist/app`. The Android project is versioned in `mobile/android/`.
- `RetourPlugin.java` forwards the system back gesture (predictive back) to the page.
- `node mobile/icones.mjs` draws the launcher icons from `public/app/perso.js`.
- `.github/workflows/apk.yml` builds the APK and publishes it in the `apk` release.
- The installed app downloads the published content at startup, so a new lesson does not require reinstalling.
